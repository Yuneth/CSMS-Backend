# Project Name: Cleaning Service Management System - Admin Panel (CRUD)

## Core Features

### User Functionality:

#### Register and Login to the system
#### Book a Cleaning Service
#### View and Manage Bookings

## Setup Instructions:

#### Backend: Spring Boot

#### Database: MySQL

#### Frontend: React.js with Material UI

#### API Client: Axios

#### Authentication: JWT

#### Java version: 17

#### Project Architecture: Layered Architecture

#### Controller → Service (Interface) → ServiceImpl (Implementation) → Repository → Database

#### Download and open it in IntelliJ IDEA

#### Create MySQL Database: CREATE DATABASE cleaning_system;
